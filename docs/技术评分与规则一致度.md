## 技术数据与指标

技术分析需要至少34根有效日K线和正数报价。逐根验证OHLC为有限正数，最低价不大于开/收盘，最高价不小于开/收盘。数据不足或无效时终止分析，由既有同步/SSE错误协议反馈，不构造近似行情，不保存成功报告。

- EMA12、EMA26以各自首个完整周期SMA初始化。
- DIF从第26根开始有效；DEA从首9个有效DIF初始化，第34根首次可用，避免把预热期零值混入EMA9。
- MACD柱使用未舍入DIF/DEA之差乘2，最后显示三位小数。
- RSI沿用Wilder平滑。完全平盘的平均上涨和下跌均为零时为50，只有平均下跌为零且上涨非零才为100。
- KDJ沿用9期随机指标；布林带使用20期均值与总体标准差。

技术评分从50分开始，按实际展示指标与报价加减：

| 项目 | 分项规则 |
| --- | --- |
| MACD柱 | 正值 +15，负值 -10，零值 0 |
| RSI12 | 大于50且小于70：+10；小于30：+15；大于70：-10；其余0 |
| KDJ J | 小于20：+10；大于90：-8；其余0 |
| 布林位置 | 报价低于下轨：+8；高于上轨：-8；其余0 |
| 最终限幅 | 10–95，限幅差额单独记录 |

超卖及下轨加分属于反转假设，不证明反弹已发生。技术桶：>=70偏多，<40偏空，其余中性。完全平盘序列的RSI为50、MACD柱为0、技术总分为50。

新增 `sampleSize`、`scoreExplanation`、`scoreContributions` 随技术JSONB保存。分项含基础分及限幅差额，加总等于最终分数；页面、历史详情和导出显示同一口径。旧报告没有这些字段时只展示已保存结果，不按新规则重算。

## 综合分与策略计划

综合分 = 技术分(0–100) × 0.5 + 舆情分(0–1) × 100 × 0.5。

修正原先舆情误乘50后再乘0.5的问题。合成接口覆盖0–100；实际技术与舆情子算法各自仍有限幅。

- 综合分>=70且规则一致度达到策略阈值：BUY。
- 综合分在[50,70)：HOLD；不足50：SELL。
- 分数达到BUY但一致度不足：HOLD，使用原有降级计划参数。
- 保守/平衡/激进的一致度阈值沿用0.70/0.65/0.60；仓位、止损、周期由既有策略配置提供。
- 目标价仍由明确的策略比例生成，在理由中标为示意参数，不能当作价格预测。

同样证据的规则一致度不因选择激进策略而增加。策略影响执行门槛和风险参数，不改变证据数值。

## RULE_AGREEMENT_V1

令T=技术分/100，S=舆情分，M=(T+S)/2：

```text
方向一致性 A = 1 - abs(T-S)
偏离中性强度 D = 2 * abs(M-0.5)
原始一致度 R = A * (0.5 + 0.5*D)
最终一致度 C = min(R, 信号覆盖上限, 数据/缓存上限)
```

最后保留两位小数，再按显示值分级：>=0.70高，[0.40,0.70)中，不足0.40低。它反映规则方向和数据约束，既不是样本统计正确率，也不是LLM自报置信度。

| 技术/舆情 | 全覆盖、新鲜数据的一致度 |
| --- | --- |
| 90/0.9 | 0.90 |
| 10/0.1 | 0.90 |
| 50/0.5 | 0.50 |
| 90/0.1 | 0.10 |

强看空与强看多对称；两者冲突会降低一致度，不能把偏多分数直接当作所有结论的置信度。

覆盖度 = 可用行情原始权重之和×0.88 + 有非空新闻时的0.12。行情权重及缺失定义见《评分口径与数据缺口》。覆盖度不等于新闻覆盖全市场的比例；原始权重、新闻窗口和关键词仍是启发式假设。

- 无PE、有涨跌幅/换手率/量能且无新闻：覆盖0.66；有新闻：0.78。
- 无覆盖度元数据或技术样本数未记录/少于34：上限0.40。
- 行情缺失或过期：上限0.50；新闻过期：上限0.60。
- 使用所有适用上限的最小值；没有技术或舆情分时为0并明确缺失。

新方法在顶部及辩论三方共用，不按角色预设乐观、悲观或固定中立置信度。界面显示“规则一致度 N/100”；旧记录仍显示历史百分比与未记录方法提示。

## 辩论模板与票数

共享 `DebateEvidence` 只从已提供指标、PE口径及舆情代理因素构造论据。单点K>D或MACD柱为正不能写成金叉或持续放大；绝对PE不能证明估值合理或同业优势；新闻条数不能证明机构看好。允许证据不足，不生成独立固定目标价和止损。

三方基础各1票。技术桶增加2票，舆情桶增加1票：舆情>=0.65偏多、<0.35偏空，其余中立。总票数6，严格过半才裁定看多/看空，其余中立。保存及展示的是实际参与裁决的完整票数，规则一致度不再偷偷增加角色票数。

仲裁用于检查观点，独立策略计划仍由同一综合分和策略门槛生成，最终信号与计划类型继续按既有协议分别保存。实际部署的LLM输出还需单独验证；本轮真实链路使用模板降级。
